# Data dictionary

## data/synthetic/synthetic_parameters.json
All parameters needed to regenerate the 30,000-scenario synthetic benchmark: seed, base criterion scores, stress effects, weight distribution, critical-risk model, tau/alpha, and Wasserstein clustering metadata.

## data/contamination/directed_contamination_path.csv
One row per directed-contamination level. Contains contamination fraction, actual TV distance, true first-rank probabilities, true safety probabilities, unconstrained top alternative, and oracle safe choice.

## data/contamination/random_contamination_replications.csv
Frozen row-level random-contamination experiment. Key columns: `delta`, `rep`, `method`, `choice`, `oracle_choice`, `accuracy`, `indecision`, `safety_violation`, and historical `false_robustness` (renamed `oracle_disagreement` in final analysis).

## data/governance/public_source_statistics.csv
Extracted public statistics and qualitative anchors. Fields: source ID, organization, title, URL, statistic, value, type, sample size where applicable, use in model, and access date.

## data/governance/policy_feature_coding.csv
Binary or interval coverage coding for the control/audit practices used to compute g5 and g6. Every row includes a source-ID trail.

## data/governance/final_matrix_audit.csv
The complete 24-cell audit trail. For every alternative × criterion cell it stores lower/upper bounds, the explicit coding rule, and source URLs.

## results/governance/*.csv
Final public-data matrix, unfiltered DR-SMAA, safety-filtered DR-SMAA, and feasibility sensitivity.

## results/synthetic/*.csv
Generated by `01_synthetic_benchmark.py`; these are the corrected authoritative synthetic outputs.

## results/contamination/*.csv
Final contamination metrics, confidence intervals, and publication subsets.
